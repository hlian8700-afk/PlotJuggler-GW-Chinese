# 故障分析：阶段①基础代码

基线：BladeScope 3.17.0.18。此分支尚不替换稳定版，也不自动发布安装包。

## 本次实现

- 纯 C++17 核心：厂商/机型/控制器隔离，同轴组合条件，三值证据，草稿规则禁用，明确的 SC 对时方向，按毫秒持续时间判定，跨文件覆盖与缺口识别。
- 外部配置导入器：只使用 Python 标准库读取 ZIP/CSV/XLSX；不依赖 Excel，不执行公式；忽略伪造的百万行 dimension，保留源表/行号/哈希及未命名列。
- SQLite 草稿包：原记录、别名、代码索引、冲突与清洗问题；不覆盖已有输出。
- 测试全部使用合成数据，不含真实机组台账、录波、网络路径或上传的原配置内容。

## 本地导入

```sh
python tools/import_diagnosis_config.py /path/to/config.zip --output /private/path/diagnosis-draft.sqlite
```

输出为草稿台账，不是已验证可执行规则。文字特征、旧优先级、单位和机型适用性必须复核；不得通过改状态字段替代案例验收。

## 语义

- SC 对齐时间 = SC 原始时间 + offset_ms。正值将 SC 向后移动，TR 不变。
- UNKNOWN 不视为无故障。反证使候选不适用，只有可比较且覆盖完整的矛盾证据才标冲突。
- 文件覆盖与测点覆盖分开记录；跨日拼接不能填补信号缺测。
- 首触不等于根因；未验证规则不参与自动结论。
